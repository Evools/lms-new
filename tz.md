# Проект

Разработай современную веб-платформу для лицея.

Важно понимать, что это НЕ электронный дневник и НЕ замена платформы "Э-Күндөлүк".

В лицее уже используется Э-Күндөлүк, где ведутся:

- оценки;
- расписание;
- информация для родителей.

Моя система должна стать внутренним рабочим пространством лицея и современной LMS.

Основная цель проекта — облегчить работу преподавателей, администрации и студентов.

Проект должен иметь современный интерфейс уровня Notion, Linear, Vercel Dashboard, GitHub или ShadCN UI.

Минимализм, аккуратные карточки, большие отступы, современная типографика и удобный UX.

------------------------------------

# Роли пользователей

1. Администратор
Полный доступ ко всей системе.

2. Преподаватель
Работает только со своими группами.

3. Студент
Видит только свои группы, материалы и задания.

------------------------------------

# Основные разделы

## Dashboard

Главная страница.

Администратор должен видеть:
- количество групп;
- количество преподавателей;
- количество студентов;
- последние действия;
- объявления;
- сегодняшних дежурных.

Преподаватель должен видеть:
- сегодняшние занятия;
- домашние задания на проверку;
- группы;
- объявления;
- быстрые действия.

Студент должен видеть:
- последние материалы;
- домашние задания;
- объявления;
- является ли сегодня дежурным.

------------------------------------

## Группы

Это основной раздел системы.
Например

ИС-1-25

Внутри группы:
- Обзор
- Студенты
- Материалы
- Домашние задания
- Посещаемость
- Дежурство
- Староста
- Документы
- Объявления

Все действия преподавателя происходят внутри группы.

------------------------------------

## LMS

Каждый преподаватель может:

- создавать темы;
- создать тест;
- публиковать материалы;
- прикреплять PDF;
- прикреплять Word;
- прикреплять презентации;
- прикреплять видео;
- прикреплять ссылки;
- создавать домашние задания;
- принимать выполненные задания;
- оставлять комментарии.

------------------------------------

## Посещаемость

Преподаватель открывает занятие.

Напротив каждого студента можно выбрать:

- Присутствовал
- Отсутствовал
- Опоздал
- Уважительная причина

История посещаемости должна храниться автоматически.

------------------------------------

## Домашние задания

Преподаватель может:

- создать задание;
- указать срок сдачи;
- прикрепить материалы.

Студент может:

- загрузить файл;
- оставить комментарий.

Преподаватель может:

- проверить;
- оставить комментарий.

Оценки НЕ ставятся, так как они выставляются в Э-Күндөлүк.

------------------------------------

## Материалы

Хранилище материалов.

Типы:

- Лекция
- Практика
- Лабораторная
- Видео
- PDF
- Документ
- Ссылка

------------------------------------

## Дежурство

Отдельный модуль.

Функции:

- назначить дежурных;
- назначить старшего;
- автоматическое распределение;
- история дежурств;
- календарь дежурств;
- отображение сегодняшних дежурных.

------------------------------------

## Староста

Каждая группа имеет:

- Старосту;
- Заместителя старосты;
- Классного руководителя.

------------------------------------

## Объявления

Можно публиковать:

- всему лицею;
- группе;
- преподавателям.

Поддержка:

- текста;
- изображений;
- файлов.

------------------------------------

## Документы

Внутренние документы лицея.

Например:

- методички;
- положения;
- инструкции;
- шаблоны документов.

------------------------------------

## Отчёты

Система должна автоматически строить отчёты.

Например:

По группе:

- посещаемость;
- количество домашних заданий;
- активность студентов.

По преподавателю:

- проведённые занятия;
- выданные задания;
- проверенные задания.

По студенту:

- посещаемость;
- выполненные задания;
- пропущенные задания.

------------------------------------

# Главная идея проекта

Проект НЕ должен повторять Э-Күндөлүк.

Он должен стать внутренней цифровой платформой лицея, объединяющей:

- LMS;
- управление группами;
- посещаемость;
- домашние задания;
- материалы;
- дежурства;
- отчётность;
- объявления;
- документы.

Все решения должны быть ориентированы на удобство преподавателей и администрации, а интерфейс должен быть современным, минималистичным и максимально удобным для ежедневной работы.
