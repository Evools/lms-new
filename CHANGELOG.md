# Журнал обновлений и дорожная карта LMS

---

## 🚀 Выполненные обновления (Текущий релиз)

### 1. 🛡️ Синхронизация Посещаемости и Сводная Статистика
- **Модуль сводной аналитики посещаемости за период**:
  - Добавлена вкладка **«Сводная статистика»** в журнале посещаемости (`/dashboard/attendance`).
  - Быстрые пресеты выборки: *«Текущая неделя»*, *«Текущий месяц»*, *«Прошлый месяц»*, *«Семестр»*, *«Учебный год»* и *«Произвольный диапазон дат»*.
  - Фильтрация по *всем дисциплинам группы* или по *конкретному предмету*.
  - Карточки сводных KPI: общее число проведенных пар, средняя посещаемость группы (`%`), сумма отметок присутствия, пропусков (НБ), опозданий и уважительных причин (справки).
  - Сводная таблица по всем студентам группы с прогресс-барами, сортировкой (по посещаемости, по количеству НБ, по алфавиту) и поиском.
  - Экспорт в Excel / CSV с кодировкой UTF-8 BOM и печать ведомости.
- **Слушатель несохранённых данных**:
  - Добавлен перехватчик `beforeunload` при закрытии/перезагрузке вкладки с несохранённой ведомостью.
  - Добавлен компактный диалог подтверждения при попытке смены группы, даты или предмета внутри приложения.
- **Горячие клавиши для быстрой переклички (Roll Call Mode)**:
  - $\uparrow$ / $\downarrow$ (или `k` / `j`) — выбор следующего/предыдущего студента в списке.
  - `1` — Был (`PRESENT`)
  - `2` — НБ (`ABSENT`)
  - `3` — Опоздал (`LATE`)
  - `4` — Справка (`EXCUSED`)
  - `Ctrl + S` / `Cmd + S` — Быстрое сохранение ведомости.
  - Подсказка по горячим клавишам в нижней панели.
- **Интеграция с дежурствами**:
  - Бейдж `🛡️ Дежурный` для дежурных студентов в ведомости посещаемости.
  - Предупреждающий баннер в графике дежурств (`/dashboard/duty`) при неявке назначенного дежурного с кнопкой быстрой замены.

### 2. 📝 Конструктор тестов (`/dashboard/lms/tests/new` & `[id]/edit`)
- **Компактный навигатор по вопросам (Questions Mini-Map)**:
  - Плиточная сетка номеров вопросов ($1, 2, 3...$) — занимает минимум вертикального пространства (~50–80px).
  - Индикаторы готовности вопросов (зелёный — заполнен; янтарный с пульсацией — требует заполнения текста/ответа).
  - Переключатель между компактной сеткой плиток и списком с описанием.
  - Возможность свернуть/развернуть навигатор в один клик.
  - Плавный скролл к вопросу с акцентной подсветкой при клике на номер.
  - Счётчик суммы баллов и прогресс (`X из Y вопросов готово`).

### 3. 📂 Домашние задания (`/dashboard/assignments`)
- **Декомпозиция модальных окон на подкомпоненты**:
  - `view-assignment-dialog.tsx`: просмотр описания, вложений и дедлайна.
  - `student-result-dialog.tsx`: карточка результата студента, оценка, рецензия учителя.
  - `student-submit-dialog.tsx`: многофайловый редактор кода (HTML, CSS, JS, React, PHP, Python), живое превью и отправка ссылок.
  - `teacher-review-dialog.tsx`: кабинет проверки работ с поочередным конвейером (Focus), быстрыми шаблонами рецензий и оценками.
  - `delete-assignment-dialog.tsx`: компактное подтверждение удаления.
  - `create-assignment-dialog.tsx`: быстрое создание задания.
  - `submission-content-display.tsx`: превью решения и скачивание проекта в `.zip`.
- **Сохранение состояния в URL (Query Params)**:
  - Параметры `?group=...&subject=...&tab=...&search=...` теперь сохраняются в адресной строке.
  - При перезагрузке страницы или переходе назад/вперёд фильтры не сбрасываются.
